- **72**：HWC → 转成 `(H, W, C) = (行, 列, 波段)`，后面网络里就是

- **75–76**：**这是理解训练目标的关键两行**。
  - `image`（网络输入）= 原图去掉最后一行 → 行号 `0 … H-2`；
  - `label`（监督目标）= 原图去掉第一行 → 行号 `1 … H-1`。

  于是输入第 t 行恰好是目标第 t 行的**上一行**，网络学的是“用第 y−1 行（及其过去）预测第 y 行”。
  与论文 Alg. 1 的 `for y = 1, … do` 完全对应，也和 `model.py:401`
  `delta = a[:,1:,:] - x_spatial[:,:-1,:]`（用第 t 行的预测去比第 t+1 行的真值特征）严丝合缝。
- **77**：`(image, label)` 两个 tensor。`train.py:31` 的 `DataLoader` 直接把它们打包成
  `x, y`，所以 `model.py:442` 里写的是 `x, y = batch`。

### B.2 一个容易被忽略的后果

因为验证集 `val_loader` 是 `HySpecNet11k(config, mode='val')`，而 `__getitem__` 里
`mode != "train"` 分支用全波段，所以 **`train.py` 的 `val_l1` 指标是在 202 波段、
未裁剪、除以 1000 的尺度上算的**，与训练时的 16 波段尺度不同。这只影响日志，不影响权重。
